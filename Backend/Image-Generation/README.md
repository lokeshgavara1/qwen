# Image Generation Model Directory

Place your Stable Diffusion model weights in this directory.

### Default Expected Model:
- **Filename**: `v1-5-pruned.safetensors` (or any custom SD1.5 checkpoint)
- **Path**: `Backend/Image-Generation/v1-5-pruned.safetensors`

### Download Reference:
You can download the Stable Diffusion v1.5 pruned safetensors from Hugging Face:
- [runwayml/stable-diffusion-v1-5](https://huggingface.co/runwayml/stable-diffusion-v1-5/blob/main/v1-5-pruned.safetensors)

> **Note**: `.safetensors` and large weight files are ignored by git in `.gitignore` because they exceed GitHub's 100MB file limit.
